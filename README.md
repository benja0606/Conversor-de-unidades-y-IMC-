
# 📊 Calculadora de IMC (Índice de Masa Corporal)

Una aplicación sencilla e intuitiva para calcular el **Índice de Masa Corporal (IMC)** a partir de la estatura y el peso de una persona, proporcionando una clasificación rápida del estado nutricional (bajo peso, peso normal, sobrepeso u obesidad).

---

## 🚀 Características

- 📏 **Cálculo preciso:** Aplica la fórmula oficial del IMC ($\text{IMC} = \frac{\text{peso}}{\text{estatura}^2}$).
- 🏷️ **Categorización:** Clasifica el resultado según las categorías estándar de salud.
- ⚡ **Interfaz limpia e intuitiva:** Fácil de usar para cualquier usuario.
